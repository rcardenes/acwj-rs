## ACWJ - in Rust

Reimplementation of the C (subset) compiler featured in Warren Toomey's [A Compiler Writing Journey](https://github.com/DoctorWkt/acwj). Reimplemented in Rust for the extra challenge.

# Note on AI usage:

I'm writing the compiler on my own because it's an educational project. I'm using AI mostly
for test coverage sampling and to suggest tests I haven't thought of.
